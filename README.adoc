# ⚖️ Legal GraphRAG Assistant

A GraphRAG-powered chatbot that answers students' legal and policy questions by
combining a Neo4j knowledge graph with vector retrieval and an LLM — grounding
answers in the Nigerian Constitution and the Benson Idahosa University student
handbook instead of hallucinating.

🔗 **Live demo:** https://law-graphkb.streamlit.app/
**Sample output:** https://github.com/Aibuedefe-bot/Graph-RAG/blob/main/sample_output
(sample_output.jpeg)

## Why GraphRAG?
Plain RAG retrieves isolated text chunks. A graph captures *relationships* between
legal concepts, sections, and clauses — so the assistant reasons across connected
provisions, not just the nearest paragraph.

## What it does
- Answers questions on the Nigerian Constitution and BIU student handbook
- Retrieves over a Neo4j graph + vector index for grounded, traceable answers
- Clean Streamlit chat interface built for students

## Architecture
Streamlit UI → OpenAI LLM → Neo4j graph + vector retrieval → grounded answer

## Stack
Python · Neo4j · OpenAI · LangChain · Streamlit

## What I built
Started from Neo4j GraphAcademy's LLM-chatbot foundation, then extended it into a
legal-domain assistant: ingested and modelled the Nigerian Constitution and the BIU
student handbook into the graph, wired in OpenAI for generation, and built a custom
Streamlit frontend for students.

## Run it locally
1. `pip install -r requirements.txt`
2. Add your Neo4j + OpenAI keys to `.streamlit/secrets.toml`
3. `streamlit run bot.py`
